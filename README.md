# Xonadonim.uz — 3D Interaktiv PropTech Platformasi

O'zbekistonning 1-raqamli 3D arxitektura va PropTech ekotizimi.

## Imkoniyatlar:
- 🌆 **Procedural 3D Tower & Tashkent Skyline**: Three.js va maxsus materiallar asosida yaratilgan zamonaviy turar-joy majmuasi.
- 💥 **3D Exploded Floor View**: 7-qavat planirovkasini fazoviy ajratib, xonalar (mehmonxona, yotoqxona, oshxona, balkon) o'lchamlarini real ko'rish.
- 📐 **3D Blueprint (Rentgen)**: Arxitektura chizmasi va x-ray simulyatsiyasi.
- 🏆 **100-Ballik Sifat Simulyatori**: Immobiliare.it standarti bo'yicha e'lon sifatini oshirish va 3D minorada qavatlarni yoritish.
- 🔊 **Fazoviy Ovoz (Web Audio API)**: Tashqi fayllarsiz toza sintetik fazoviy ovoz effekti.
- 🤖 **Telegram Web App & Click Integratsiya**: `@XonadonimRobot` orqali 10 soniyada e'lon joylash.
